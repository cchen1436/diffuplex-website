# Diffuplex

Full-duplex Spoken Language Modeling with Discrete Diffusion.

Project page: https://cchen1436.github.io/diffuplex-paper-site/

Static website; no build step required. Open index.html directly or serve this directory with `python3 -m http.server`. The generation demo is pending: add assets/speed-demo.mp4 and set the data-src of #speed-video in index.html.

Author-confirmed GB300 throughput is 1,872 decode tokens/s on average, not peak throughput.

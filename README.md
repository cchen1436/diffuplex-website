# Diffuplex

Full-duplex Spoken Language Modeling with Discrete Diffusion.

Project page: https://cchen1436.github.io/diffuplex-website/

Static website; no build step required. Open index.html directly or serve this directory with `python3 -m http.server`. The revised 34.1-second generation demo is included at assets/speed-demo.mp4. It starts muted, with a Replay with sound control for the spoken question. The video shows real-time generation, 30× slow motion, and equal-length comparisons.

Author-confirmed GB300 throughput is 1,872 decode tokens/s on average, not peak throughput.
